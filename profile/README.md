# Profile (optional)

This folder is empty on purpose. The Scout runs without it.

To personalize:
1. Copy `PROFILE_TEMPLATE.md` to `profile.md` and fill in what you want. Leave anything blank.
2. For the safety gate to size money plays against your real numbers, also copy `numbers.template.json` to `numbers.json` and fill it in.

Update either file whenever your situation changes. The Scout re-reads them on every run.

Privacy: these files stay in your private repo. The Scout never copies them into the engine and never puts your details in a web search. Do not put account numbers, ID numbers or passwords here; it does not need them.
